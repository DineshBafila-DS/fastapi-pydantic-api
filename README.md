# fastapi-pydantic-api

# FastAPI Pydantic Multiplication API

A simple FastAPI project demonstrating how to create a POST API and use **Pydantic models for input validation**.

## Features

- FastAPI application
- POST API endpoint
- Pydantic model for data validation
- JSON request body
- Multiplication of two integers
- Automatic validation of input types
- Testing using Swagger UI, Postman, cURL, and Python Requests
